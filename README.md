# モダンチェス

Delta Chatのチャット内で遊べるwebxdc用チェスアプリです。CPUとの一人対戦と、チャット相手との通信対戦に対応しています。

- 配布ファイル：`Modern-Chess-1.0.4.xdc`
- バージョン：1.0.4
- 表示言語：日本語

## 主な機能

- CPU対戦：自分が白・黒のどちらでも開始できます。
- 通信対戦：募集・参加方式の2人対戦と観戦に対応しています。
- SVGの駒：端末の文字フォントに依存しない、統一した形の駒を表示します。
- 移動できるマスの表示、直前の着手の強調、チェックの表示。
- キャスリング、アンパッサン、4種類の駒への昇格。
- チェックメイト、ステイルメイト、駒不足、50手ルール、3回同形の判定。
- 投了、通信対戦での合意ドロー、色を交代した再戦。
- 移動・駒の取得の効果音と、オン／オフ切り替え。
- 通信履歴からの局面復元と、反映待ちが続く場合の再送操作。

## 起動する

1. Delta Chatで、遊びたいチャットに`Modern-Chess-1.0.4.xdc`を添付して送信します。
2. チャットに表示されたアプリ投稿を開きます。起動ボタンの名称は端末によって異なります。
3. 開始メニューで、CPU対戦または「チャット相手と対戦」を選びます。

別のアプリストアからのインストールや、外部ライブラリのダウンロードは不要です。

## CPUと対戦する

1. 「CPUと対戦（あなたが白）」または「CPUと対戦（あなたが黒）」を選びます。
2. 白が先手です。黒を選んだ場合、CPUが先に指します。
3. 自分の番に駒を動かすと、CPUが自動で応答します。

自分の駒が手前になるように盤面が表示されます。CPUは簡易な2手先読みです。難易度の切り替えはありません。

**CPU対戦は保存されません。** アプリを閉じたり、メニューからCPU対戦を開始し直したりすると、新しい対局になります。

## チャット相手と対戦する

**2人とも、同じチャットの同じアプリ投稿を開いてください。** 同じxdcファイルでも、別々の投稿を開くと別の対局になります。

1. 2人とも「チャット相手と対戦」を選びます。
2. どちらか一方が「白で募集」または「黒で募集」を押します。選んだ色が募集する人の担当色です。
3. もう一方は、募集が表示されたら「参加する」を押します。残った色を担当します。
4. 白の人から対局を始めます。

募集を取りやめる場合は「募集を取り消す」を押します。すでに2人が対戦している場合、他の人は観戦できます。

### 通信と再開

- 着手はDelta Chatの通信を通じて相手に反映されます。即時に届くとは限りません。
- 「送信待ち」の間は、次の通信操作ができません。
- 反映待ちが15秒以上続くと「反映を再確認・再送」が表示され、同じ操作を再送できます。
- 同じアプリ投稿を開き直すと、受信済みの通信履歴から局面を復元します。復元中は待ってください。
- まだ届いていない相手の手は、受信後に反映されます。

## 駒を動かす

1. 自分の番であることを確認します。
2. 動かしたい自分の駒をタップします。
3. 移動できるマスに黒い点が表示されます。相手の駒を取れるマスは枠で示されます。
4. 行き先をタップすると移動が確定します。

パソコンではタップをクリックと読み替えてください。ドラッグは不要です。

- 同じ駒をもう一度タップすると選択を解除できます。別の自分の駒をタップすると選び直せます。
- 自分のキングが相手に狙われる状態になる手は指せません。
- 黄色は直前の移動元・移動先、赤色はチェックされているキングの目印です。
- 確定した手を取り消す機能はありません。

### 特殊な手

| 操作 | 指し方 |
| --- | --- |
| キャスリング | 条件を満たす場合、キングをルークの方向へ2マス動かします。ルークも自動で移動します。 |
| アンパッサン | 相手のポーンが2マス進んで自分のポーンの真横に来た直後、そのポーンが通過した斜め前のマスへ移動します。合法な場合だけ候補が表示されます。 |
| 昇格 | ポーンが相手側の一番奥の段に着くと、クイーン・ルーク・ビショップ・ナイトから選びます。「選び直す」で確定前の操作へ戻れます。 |

## 効果音

画面上部の「効果音：オン／オフ」を押すと切り替わります。

- 通常の移動は短い1音、駒を取るときは2音です。
- CPUや通信相手の着手にも対応しています。
- 音はアプリ内で合成するため、音声ファイルのダウンロードは不要です。
- 最初に画面を操作してから再生できるようになります。
- 過去の通信履歴の復元時や、画面が非表示のときは鳴りません。
- オン／オフの設定は、端末内の保存機能が利用できる場合に記憶されます。相手とは同期しません。

音が出ない場合は、効果音の設定と端末の音量・消音設定を確認してください。端末側の再生制限によって鳴らない場合もあります。

## 終了と再戦

| ボタン | 動作 |
| --- | --- |
| 投了 | 「本当に投了？」に変わってから3秒以内にもう一度押すと、自分の負けで終了します。 |
| ドロー提案／ドローに同意 | 通信対戦で双方が同意すると引き分けになります。次の着手があると提案は解除されます。 |
| 引き分けにする | CPU対戦の練習を引き分けで終了します。 |
| 最初から | CPU対戦を同じ色で初期局面から開始し直します。 |
| もう一度（色を交代） | CPU戦の終了後、白黒を交代して開始します。 |
| もう一度（色替えで再戦） | 通信戦の終了後、対戦者が押すと白黒を交代して新しい対局を開始します。 |
| ‹ メニュー | 開始メニューへ戻ります。通信対戦で押しても投了にはなりません。 |

50手ルールと3回同形は、このアプリでは申告を必要とせず、自動で引き分けにします。

## 困ったとき

| 症状 | 確認すること |
| --- | --- |
| 駒が動かない | 自分の番、自分の駒、移動先の印を確認してください。観戦者は動かせません。 |
| 移動先が表示されない | 他の駒にふさがれている、またはチェックを防げない可能性があります。別の駒を選んでください。 |
| 相手が参加できない | 同じアプリ投稿を開いているか確認し、一方が募集、もう一方が参加してください。 |
| 送信待ちが続く | Delta Chatで送受信できているか確認してください。再送ボタンが出た場合は押せます。送信できないチャットでは送信権限も確認してください。 |
| 募集や相手の手が届かない | 配送に時間がかかる場合があります。双方の通信状況と、開いているアプリ投稿を確認してください。 |
| CPU戦の続きが見つからない | CPU対戦には保存・再開機能がありません。新しい対局を開始してください。 |

## 旧版から使い替える

修正版のxdcファイルをチャットに新しく添付して開いてください。既存のアプリ投稿は上書きされません。新しい投稿は別の対局として始まるため、通信相手にも同じ新しい投稿を開いてもらいます。

## アプリの構成

xdcファイルは、次のファイルをルートに置いたZIP形式のパッケージです。

```text
Modern-Chess-1.0.4.xdc
├── index.html      画面、チェスエンジン、CPU、同期処理、SVG駒、効果音
├── manifest.toml   アプリ名、バージョン、説明
└── icon.png        アプリアイコン
```

外部ライブラリへの依存はありません。通信にはwebxdcの`sendUpdate()`と`setUpdateListener()`、利用者の識別には`selfAddr`を使います。`webxdc.js`はDelta Chatが提供するため、パッケージには同梱していません。

効果音にはWeb Audio APIを使います。ブラウザーで`index.html`を直接開いた場合はテスト用の自己受信処理が使われ、実際の相手との通信にはなりません。

- 対局終了後のCPU着手を防止。
- 反映待ちが続く通信イベントの再送操作を追加。

## 検証状況

アプリのJavaScriptとwebxdc APIの模擬環境で、以下を確認しています。

- 初期局面の合法手探索：深さ1で20、深さ2で400、深さ3で8,902。
- キャスリングを含む検証局面の合法手探索：深さ1で48、深さ2で2,039。
- アンパッサン、不合法なアンパッサンの禁止、4種類の昇格。
- チェックメイト、ステイルメイト、駒不足、50手ルール、3回同形。
- CPUの24半手の進行で合法手を選択。
- 通信履歴の到着順を変えた場合の局面一致、観戦者と古い局面への着手の拒否、合意ドロー、再戦。
- 効果音の開始条件、移動と取得の鳴り分け、消音、設定保存、非表示時の抑制、音声APIがない場合の動作。

実際のDelta Chatの2端末間送受信、端末ごとの表示・タッチ操作・音声再生は未検証です。
